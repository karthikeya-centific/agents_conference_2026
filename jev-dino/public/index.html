Who plays?

Several times a second the game describes its state in text and asks typed questions: what should the dino do about the nearest obstacle, and about the one after it? The model answers jump, duck or run per obstacle; the game presses the key at the right frame. Nothing is remembered between calls. Jev, TypeSafe's System One model, answers such questions in roughly 100–500 ms with a probability for every option and never generates text. Compare it with any LLM on OpenRouter.

Game
Chrome starts at 6 and tops out at 13. Slower speeds give slow models a fighting chance.
Advanced
Harness-timed needs one correct answer per obstacle before its jump window closes. Reflex needs a decision to land inside a ~300 ms window, which a 300–500 ms model cannot do reliably.
Calls are stateless, so two can overlap. More than that queues up at the API and every answer arrives late (a 100 ms interval with 8 in flight measured 1.5–2 s per answer against the real Jev API).
